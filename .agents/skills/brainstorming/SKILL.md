# Interactive Brainstorming Protocol

Before typing a single line of implementation code:

## 1. Requirement Clarification
- Ask targeted, high-value questions to uncover true intent.
- Clarify trade-offs: speed vs. scalability, simplicity vs. flexibility.

## 2. Solution Alternatives
- Propose 2–3 distinct architectural options (e.g. Option A: Minimal change, Option B: Modular abstraction, Option C: Event-driven).
- Highlight the pros and cons of each approach with concrete code snippets.

## 3. Consensus Alignment
- Seek alignment before transitioning into the planning or execution phase.
